## Файлы

Редакция 1.1, 07.11.2026. Каждый документ лежит в двух форматах — исходник и
собранный из него PDF.

| Файл | Что это |
|---|---|
| `The_Ghost_in_the_Context_Window_Trilogy_v1.1_ru.md` | Русская редакция, исходный текст |
| `The_Ghost_in_the_Context_Window_Trilogy_v1.1_ru.pdf` | Она же, 20 страниц |
| `The_Ghost_in_the_Context_Window_Trilogy_v1.1_en.md` | Английская редакция, исходный текст |
| `The_Ghost_in_the_Context_Window_Trilogy_v1.1_en.pdf` | Она же, 18 страниц |
| `ANCHOR_TRANSLATION_NOTE.md` | Отдельная записка: почему в английском тексте якорь `# ANCHOR`, а в архивах `# ЯКОРЬ`. Пре-регистрированный A/B, 768 проб, эквивалентность ±10 п.п. |
| `ANCHOR_TRANSLATION_NOTE.pdf` | Она же, 7 страниц |
| `build_pdf.py` | Сборка: markdown → HTML → headless Chrome |

Записка нужна именно потому, что английская редакция печатает `# ANCHOR`, а
исполнялось везде `# ЯКОРЬ`. Без неё читатель, повторяющий промпт по статье,
получит текст, которого не было ни в одном прогоне.

## Как собраны PDF

```bash
pip install markdown
python build_pdf.py The_Ghost_in_the_Context_Window_Trilogy_v1.1_ru.md
```

Зависимость одна — `markdown`. Дальше HTML печатает Chrome в headless-режиме.
Путь к браузеру по умолчанию стандартный для Windows; если Chrome установлен
иначе, задайте `CHROME_PATH`.

Формулы в исходниках записаны как `$...$`. Отдельного LaTeX-движка нет: набор
команд переводится в Unicode точечно, а неизвестная команда остаётся в тексте
как есть — чтобы её было видно в готовом PDF, а не потерять молча.

До 07.11 в этом каталоге лежал один файл `The_Ghost_in_the_Context_Window_Trilogy.md`
(редакция 1.0), а собранный из него PDF — в корне репозитория. Оба удалены:

якоре. Прежние версии остаются в истории git — удаление не стирает их.

**Запись на Zenodo пока содержит PDF редакции 1.0** (собран инструментом
Antigravity, 599 298 байт). PDF в этом каталоге собраны из редакции 1.1 другим
движком, поэтому побайтно с опубликованным не совпадают и не должны: сверять
надо текст, а не размер файла.
