# The Ghost in the Context Window — трилогия

Три научно-популярные статьи об одном исследовании: 1 416 канонических проб на
авторегрессионных трансформерах. Текст написан от первого лица в конце
исследовательской сессии — это рассказ участника о том, что происходило, а не
пересказ со стороны.

· CC BY 4.0 · русский

## Файлы

| Файл | Что это |
|---|---|
| `The_Ghost_in_the_Context_Window_Trilogy.md` | Исходный текст всех трёх статей |
| `build_pdf.py` | Сборка PDF: markdown → HTML → headless Chrome |

Опубликованный PDF лежит в корне репозитория:
[`The_Ghost_in_the_Context_Window_Trilogy.pdf`](../The_Ghost_in_the_Context_Window_Trilogy.pdf).
Он же загружен в Zenodo, и именно он — эталон: пересборка может отличаться на
несколько килобайт, потому что вёрстку делает Chrome, а его версии дают разный
вывод при одинаковом входе.

## Пересборка

```bash
pip install markdown
python build_pdf.py
```

Скрипт читает `.md` рядом с собой и пишет PDF в корень репозитория. Путь к Chrome
по умолчанию — стандартный для Windows; если браузер установлен иначе, задайте
`CHROME_PATH`:

```bash
CHROME_PATH=/path/to/chrome python build_pdf.py
```
