## Directories

### `hooks/` — 4 tracked files + a local log, 64 KB
`pre_tool_use_guard.py` (PreToolUse hook: blocks a hanging command before it
runs), `antigravity_guard.py` (same gate for the Antigravity harness; deny is
exit 0 with `{"decision": "deny"}`, so the exit code alone proves nothing),
`README.md` / `README_RU.md` (wiring for each harness). `quote_guard.log` is the
hook's runtime output: it sits next to the hook and is gitignored, so it is not
part of the tree.

### `exports/` — one passport tracked, transcripts never
Session exports are produced locally by `tools/export_session.py` and
`tools/ds_share.py`. The transcripts (`.jsonl`) are gitignored and never
published: they contain personal material. One passport is published —
`77556605-….meta.json` — because the dossier cites its figures (16/86 damaged
chunks, 5 840 records), and a reader should be able to check them without the
7.9 MB transcript. `.gitignore` names that file explicitly, so a future export
does not become public by accident.

`tests/` requires editing this file.

## What is deliberately not here

On 2026-11-16 the publication sources were moved out of the repository to a
local archive (`C:\1\Arhiv`): `paper/` (preprint v3.0 LaTeX and its arXiv
archive), `protocol/` (protocol v2.0 and the by-reference specification),
`trilogy/` (trilogy v1.2 markdown and PDF builder), `zenodo/` (registry
snapshot), `DEGRADATION_RU.md`, `DEGRADATION_EN.md`.

Reasons: the repository is the guard and its verification bundle; the deposited
artefacts are the PDFs, and those stayed. A reader who needs the sources finds
them in the published records, not in the tree.

Consequence to know about: `reproducibility/check_protocol.py` reads the
dossier, so it resolves documents through `find_doc()` — the repository first,
then `<root>/Arhiv`. Items 8c/8d and 10 keep working only because of that
fallback; without it they silently lose their inputs.

## Invariants

- The numbers in `PUBLICATION_PDF/` are canonical. `check_protocol.py` item 8
  compares them against `verify_numbers.py` and must stay clean on all four
  documents it reads.
- The five DOIs in `README.md` are version DOIs, not concept DOIs. A new version
  of any work gets a new DOI and the table changes; the old row moves to the
  "earlier versions" paragraph.
- `PUBLICATION_PDF/` is a copy of what Zenodo serves, byte for byte. If a file
  here differs from the deposited one, the deposited one wins and this copy is
  wrong.
